From slices to a working broker

Your four Go files, in order.

You already have slices, pointers, and UTF-8 down (main.go, readme.md). This path is the dependency chain from there to the four stubs sitting empty in your repo — the trie matcher, the promise, the job queue, the server — then wires them into one broker. Each module names the concept, translates it from the OOP/JS world you're coming from, and points at the exact file you'll write.

Build your real stubs, not toys Test the edge cases as you go Stdlib only — no frameworks Read errors out loud
Everything here runs on the standard library alone — no dependencies to install past Go itself.
Start each project with go mod init example/name and run it with go run .
Progress is saved in this browser only.
